# Протокол лабораторной работы №5

## Формулировка задания

Вариант 1 — «Крестики-нолики».

Необходимо написать приложение на языке Java с использованием библиотеки JADE. Требуется разработать агента, который умеет играть в простую настольную игру. Для проверки необходимо запустить два экземпляра разработанного агента и заставить их играть друг против друга.

## Цель лабораторной работы

Цель лабораторной работы — научиться разрабатывать мультиагентные системы с интеллектуальными агентами, реализовать обмен сообщениями между агентами и проверить корректность их взаимодействия на примере простой настольной игры.

## Краткое описание реализации

В работе реализована игра «Крестики-нолики». Каждый игрок представлен отдельным агентом JADE. Агент регистрирует свою услугу в Directory Facilitator, находит второго агента и обменивается с ним ACL-сообщениями.

Первый агент запускается с аргументом `starter`, получает роль `X` и выполняет первый ход. Второй агент автоматически получает роль `O`. После каждого полученного хода агент обновляет локальное состояние игрового поля, проверяет наличие победителя или ничьей, после чего выбирает ответный ход.

Интеллектуальное поведение агента реализовано в классе `MoveSelector`. Для выбора оптимального хода используется алгоритм minimax, который анализирует возможные состояния игрового поля и выбирает ход с наилучшим результатом.

## Описание тестового примера

Тестовый запуск выполняется через класс `ru.vstu.lab5.Main`. При запуске создается главный контейнер JADE с графическим интерфейсом RMA, после чего запускаются два агента:

```text
playerX — агент, начинающий игру, роль X;
playerO — второй агент, роль O.
```

Агент `playerX` регистрируется в DF, находит второго агента и отправляет первый ACL-запрос с состоянием игрового поля. Агент `playerO` принимает сообщение, обновляет поле, выбирает ответный ход и отправляет новое состояние поля обратно. Обмен продолжается до тех пор, пока один из агентов не победит или пока поле не будет полностью заполнено.

Корректность работы проверяется по следующим признакам:

1. оба агента появляются в RMA;
2. агенты находят друг друга через DF;
3. в консоли отображается последовательность ходов;
4. каждый ход выполняется только в свободную клетку;
5. игра завершается сообщением о победителе или ничьей.

## Вывод

В ходе лабораторной работы была разработана мультиагентная система на языке Java с использованием платформы JADE. Был создан интеллектуальный агент, способный играть в крестики-нолики и взаимодействовать со вторым агентом через ACL-сообщения. Для выбора хода применен алгоритм minimax, что позволило реализовать рациональное игровое поведение. В результате были закреплены навыки создания агентов, регистрации услуг в DF, поиска агентов, организации поведений и обмена сообщениями в JADE.
